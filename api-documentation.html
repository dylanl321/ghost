⚙️ AWS Configuration

Create a .env file with these variables:

Commercial AWS

AWS_COMMERCIAL_ACCESS_KEY_ID=your-access-key
AWS_COMMERCIAL_SECRET_ACCESS_KEY=your-secret-key  
AWS_COMMERCIAL_REGION=us-east-1

GovCloud AWS

AWS_GOVCLOUD_ACCESS_KEY_ID=your-access-key
AWS_GOVCLOUD_SECRET_ACCESS_KEY=your-secret-key
AWS_GOVCLOUD_REGION=us-gov-west-1

Additional Settings

AWS_ASSUME_ROLE_NAME=GDMSOrganizationsRole
AWS_ACCOUNTS_TABLE_NAME=gdms-accounts

🎯 API Endpoints

GET /api/health

Check API health and AWS environment status

GET /api/accounts

List AWS accounts from configured environments

POST /api/accounts/lookup

Flexible account lookup by ID, email, request ID

Body: {"accountEmail": "user@example.com"}

GET /api/accounts/list

List accounts from DynamoDB and/or Organizations

Query params: ?source=dynamodb|organizations|both&search=term

GET /api/costs/summary

Get AWS cost summary for date range

Required: ?startDate=2024-01-01&endDate=2024-01-31

GET /api/organization/structure

Get organizational unit hierarchy

GET /api/dynamodb/{table}/items

Query items from DynamoDB table

POST /api/dynamodb/{table}/items

Create item in DynamoDB table

🔧 Usage Examples

# Health check
curl http://localhost:3003/api/health

# Account lookup  
curl -X POST http://localhost:3003/api/accounts/lookup \
  -H "Content-Type: application/json" \
  -d '{"accountEmail": "user@example.com"}'

# Cost summary
curl "http://localhost:3003/api/costs/summary?startDate=2024-01-01&endDate=2024-01-31"
